# JavaScript Upper Lower String ✨

## Description

This project demonstrates the use of several powerful JavaScript string methods for cleaning, formatting, and transforming text.

The example covers:

- trim() for removing whitespace from both ends of a string.,
- trimStart() for removing leading whitespace;
- trimEnd() for removing trailing whitespace;
- toUpperCase() for converting text to uppercase;
- toLowerCase() for converting text to lowercase;
- slice() for extracting portions of a string;
- Creating a simple camelCase-style transformation.

This project is designed to help beginners understand common string manipulation techniques used in real-world JavaScript applications.

## Learning Objective 🎯

By the end of this example, you will be able to:

- Remove unwanted whitespace from strings using trim();
- Remove leading spaces with trimStart();
- Remove trailing spaces with trimEnd();
- Convert text to uppercase using toUpperCase();
- Convert text to lowercase using toLowerCase();
- Extract portions of strings using slice();
- Access individual characters using bracket notation;
- Combine string methods to create custom text transformations;
- Understand how string manipulation can improve data formatting and user input handling.

💡 This project is ideal for beginners learning JavaScript string methods and text processing fundamentals.

## How to Run (Prerequisites)

To run the project, you must have *Node.js* installed.

You can download it here:

https://nodejs.org/

## Installation

Clone the repository:

git clone https://github.com/willpaes/upper-lower-string

Navigate to the project folder:

cd upper-lower-string

Run the JavaScript file:

node upper-lower-string.js
